# Original author-provided files

The two scripts in this directory are **verbatim renamed copies of the files supplied with the paper**:
- `extended_results_original.py` — originally `run_sympy_jax_3rpr_extended_paper_results(4).py`
- `paper_simulations_original.py` — originally `run_sympy_jax_3rpr_paper_simulations(2).py`

The packaged `src/` code is the recommended entry point. The originals remain for provenance, comparison, and audit. The originals may attempt to import `robot_properties.py` and have environment-specific instructions; that external module was not included in the supplied materials. The package never silently imports it.
